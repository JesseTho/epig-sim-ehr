# Epig — SIM EHR (Student Edition)

A practice electronic health record for medical students, built to prepare them for inpatient EHR
work before they use a real system. It runs entirely in the browser.

**Open it:** https://jessetho.github.io/epig-sim-ehr/

**Training simulation only.** Every patient, clinician and value is fictional. Never enter real
patient information. Work you do is saved only in your own browser on that device.

"Epig" is a teaching parody. This project is not affiliated with or endorsed by Epic Systems
Corporation and is not for clinical use.

## What's inside

- Six fictional inpatients with charts, results, flowsheets, a medication record, notes and orders
- Order entry with allergy, interaction and lab-based advisories, and student cosign
- Learning objectives mapped to the AAMC Core Entrustable Professional Activities, with practice
  tasks that check themselves off and a short knowledge check
- Missions: short patient cases scored bronze, silver or gold, one with a live deterioration event
- A timed proficiency check with a printable certificate
- Roles: Medical Student, Physician and Nurse

## Running it yourself

Download the repository and open `index.html` in Chrome or Edge. There is nothing to install.
